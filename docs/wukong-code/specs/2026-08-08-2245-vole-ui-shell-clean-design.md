- 日期：2026-08-08 22:45
- 状态：已批准（本会话 §1 / §2 分段评审通过）
- 仓库：`vole-macos`（另仓）

## 1. 结论

Vole macOS 落地「田鼠工坊」品牌：深色壳 + 暖土内容区 + 签名「土层条（Soil Strata）」；壳用 `NavigationSplitView`，本里程碑 Clean 唯一可用模块，其余入口按「产品优先」预留并灰显。

## 2. 已锁定决策

| 项 | 结论 |
|---|---|
| 范围 | **App 壳 + Clean**（不扩 status/uninstall/optimize 实现） |
| 气质 | **田鼠工坊**（暖土、圆润、器物感；不卡通、不奶油模板） |
| 壳 | **左栏 NavigationSplitView** |
| 外观 | **跟随系统**（浅 / 深两套 token；侧栏恒定深色） |
| 侧栏模块 | **清理 · 卸载 · 优化 · 状态**；分析/历史进「更多」或设置；未实现灰显 + `soon` |
| 吉祥物 | **暖节点露脸**：空闲 / 扫描中 / 结果成功；候选勾选与确认框不出现 |
| Fur 色 | `#C99971`（用户指定） |

## 3. 品牌 token

### 3.1 色板（自 logo 取样 + 用户指定）

| 名 | Hex | 角色 |
|---|---|---|
| Burrow | `#2C211C` | 壳底（侧栏；浅/深模式恒定） |
| Soil | `#7D5D4A` | 动作（扫描 / 清理 / 确认等主 CTA） |
| Fur | `#C99971` | 品牌（选中态、土层条中段、强调） |
| Clay | `#F6F0E8` | 内容底（浅色） |
| Blush | `#F4A6A1` | 微量：成功提示 / 吉祥物腮红映射；**不**作主 CTA |
| Molehill | `#E8D5C0` | 分层 / 阴影 / 跳过区底 |
| Sage | `#C9D8B6` | App icon 底色；品牌辅助（徽章/空态），**不**作正文色 |
| Ink | `#1C1613` | 深文本辅助（正文主要用系统默认以保证对比） |

语义规则：**Fur 给壳，Soil 给动作**。侧栏选中、品牌强调、土层条用 Fur；按钮与破坏性确认用 Soil。避免正文大面积铺暖色（防「奶油 + 橙」模板感）。

### 3.2 深色模式

- 侧栏仍 Burrow；内容区改深土色（Clay 反转为深土底，具体 hex 在实现 token 时配齐并做 WCAG AA 对比校验）
- 土层条在深色下单独校验对比度

### 3.3 字体

- 界面：系统圆体优先（SF Pro Rounded 可用时），标题 letter-spacing -0.02em
- 数字 / 体积 / 路径：系统 monospace tabular
- 不引第三方字体

### 3.4 动效

- 150 / 250 / 350ms，`cubic-bezier(0.32, 0.72, 0, 1)`
- **尊重 Reduce Motion**：土层条「呼吸」退化为静态分层，取消任何抖动类动效

## 4. App 壳

- `NavigationSplitView`：左栏品牌 + 模块，右侧内容区承载当前模块
- 侧栏顶部：圆形「地道口」凹槽放田鼠 logo（径向 Burrow 渐变 + 内阴影），下排字标 `Vole` + `BURROW & SORT`
- 侧栏行：清理（READY，可用）/ 卸载 / 优化 / 状态（soon，灰显）；未实现项点击无破坏动作，可 toast「即将推出」
- 壳最小窗口延续现有 `minWidth: 520, minHeight: 420` 量级（实现时可小幅上调以容纳侧栏）

## 5. 签名元素：土层条（Soil Strata）

一条水平「土层」色带，承担体积叙事（非装饰进度环）：

- 构成：`Soil → 深棕 → Fur → Molehill` 渐变
- 三态：
  - 未扫：虚位（Clay 底 + Molehill 刻度虚线）
  - 扫描中：带呼吸动画（Reduce Motion 关闭）
  - 已选 / 结果：宽度 = 已选 / 已回收体积占比；右侧 tabular 数字
- 出现位置：空闲（虚位）→ 扫描中 → 候选（反映已选）→ 清理中 → 结果（已回收）
- **不用**在：勾选列表行、确认对话框（保持严肃）

## 6. Clean 五态（对现有 `CleanRootView` 五态的视觉映射）

同一内容区骨架：**标题带（eyebrow + 标题）＋ 土层条（如适用）＋ 主区 ＋ 底部动作条**。

### 6.1 空闲

- 标题 `翻土找缓存`；吉祥物出现（右侧或标题位）
- 土层条虚位 + 「可回收层 · 待扫描」
- 主 CTA `开始扫描`（Soil）；次信息条：`特权助手 · 未启用`（点击跳设置/启用）；角落 `FDA 已授权`

### 6.2 扫描中

- 标题 `正在翻找`；吉祥物可出现
- 土层条呼吸；`已扫 N`（tabular）；当前路径（monospace、截断）
- 动作：`取消`；注明「可取消 · 不会动文件」

### 6.3 候选列表（关键态）

- 标题 `挑要清掉的`；右上 `全选 / 全不选`
- 土层条宽度 = 已选体积占比；`已选 N · 共 M` + tabular 体积
- 列表行：勾选框 + label + 路径（monospace、截断）+ 体积；系统路径行内标 `需助手`（Soil 色系警示，不用红色）
- 「跳过」区默认折叠但可读原因（Molehill 底）
- 系统路径提示（助手未就绪）：说明**将跳过、不假装成功**
- 动作：`重新扫描` / 主 CTA `清理到废纸篓`（Enter 默认）

### 6.4 清理中

- 土层条 = 进度；用户域 → 废纸篓、系统路径 → 助手
- 动作：`取消`；注明「取消可能部分清理」

### 6.5 结果

- 吉祥物可出现；土层条 = 已回收体积
- 摘要：`✓ N 成功 · M 助手未就绪已跳过 · 0 失败`（成功用偏绿灰、跳过失色，不堆红）
- 动作：`完成`（回空闲）

## 7. 文案与状态规则

- 错误：说清**原因 + 下一步**（如互斥锁 → 稍后重试），不堆红色大字
- FDA：系统 alert 保留；壳内状态带同时显示 `FDA · 未授权`，便于回扫后复查
- 确认对话框沿用 MVP 措辞：用户域 → 废纸篓；系统路径 → 助手永久删除（未就绪则跳过）
- 全部用户可见文案走 SwiftUI 本地化（`LocalizedStringKey`），中文先行

## 8. 无障碍

- 键盘：Tab 遍历全选 / 勾选 / 主 CTA；Enter 触发默认动作；焦点环可见
- Reduce Motion：土层条动画退化（§3.4）
- 对比：Fur on Burrow、Soil CTA、深色内容区均按 WCAG AA 校验

## 9. 明确不做（本 UI 里程碑）

不实现卸载/优化/状态功能；不改 sidecar / Plan / Report / 协议 / schema；不改特权助手安全边界；不做卸载 UI；不动 CLI `vole` 仓。

## 10. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 土层条过度装饰 | 限定仅在五态骨架位出现；勾选行 / 确认框禁用 |
| 吉祥物在删除场景显轻浮 | 只在空闲/扫描中/结果成功露脸；候选与确认框不出现 |
| 深色模式土层条对比不足 | 实现时单独配深土 token 并做 AA 校验 |
| 「soon」占位误导 | 点击仅提示，无破坏动作；设置/更多收拢长尾 |

## 11. 验收清单（人工）

1. 浅色 / 深色切换：侧栏恒定 Burrow；内容区与土层条对比可读
2. 空闲 → 扫描 → 候选：勾选体积实时驱动土层条宽度与数字
3. 含系统路径且助手未就绪：列表行内「需助手」+ 提示将跳过；确认框文案与 MVP 一致
4. 结果页显示成功/跳过/失败摘要与已回收体积；「完成」回空闲
5. Reduce Motion 开启后，扫描中土层条无呼吸动画
6. FDA 未授权：alert + 壳内状态带同时可见
